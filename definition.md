2.Two Complexity Types ?
= Time and Space.

3.What is Time Complexity ? 
= Time complexity is a way to describe how the running time of an algorithm grows as the input size increases.

4.What is Space Complexity ?
= Space complexity is the amount of memory an algorithm needs to run as the input size increases.

5.What is LogN ?
= Log N tells us how many times we can divide a number by 2 until it becomes 1.
